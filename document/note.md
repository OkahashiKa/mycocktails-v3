## 画面の洗い出し

- ユーザーごとのカクテルを表示する画面
  - クエリパスにユーザー名を入力して遷移を行う？
    - 外部に公開する情報のため第三者から見られることがあっても問題ない
    - ユーザー ID は Guid にするため情報が漏れることはない
- 管理者画面
  - 材料マスタ管理画面
  - カクテルマスタ管理画面
  - ユーザー管理画面
    - この辺の機能は DB 書き換えで対応可能のため実装優先度は低め
- ユーザー管理画面
  - ログイン画面
  - ユーザー材料管理画面
  - 作成可能カクテル確認画面
    - この画面のみログイン不要とする？

## 仕様整理

- ユーザーは存在する
  - 管理者
    - 要ログイン
    - マスタ管理
    - 運用者の管理
  - 運用者
    - 要ログイン
    - ユーザー材料を登録する
  - ユーザー
    - 運用者の提供可能なカクテルの表示画面にのみアクセス可能
    - ログイン不要
